# DiLang Product Vision & 3-Year Strategic Roadmap

## 1. Product Vision Statement

To empower millions of learners worldwide to achieve true conversational fluency in any language through an offline, privacy-first, local-AI practice companion that runs natively on consumer hardware without subscription paywalls or cloud data harvesting.

## 3. Core Key Performance Indicators (KPIs)

1. **Fluency Velocity**: Mean time required for a user to reach CEFR B1 conversational competence ($< 150$ active practice hours).
2. **Review Retention Accuracy**: FSRS-v4 model predicted vs actual recall accuracy ($\ge 90\%$).
3. **Local Latency SLA Compliance**: Voice turn response time under $800\text{ms}$ total roundtrip on standard devices.
