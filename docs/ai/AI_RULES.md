# DiLang AI Coding Agent Rules & Constraints

## 1. Mandatory Directives for AI Agents

All AI coding assistants (Gemini, Claude, GPT, Antigravity) working on the DiLang codebase MUST adhere strictly to the following rules without exception.

---

## 2. Inviolable Architectural Boundaries

### Rule 1: NO Direct SQLite / Database Access from Flutter / Dart
- **Violations**: Importing `sqflite`, `sqlite3`, writing direct SQL queries in Dart, or accessing `.db` files from Flutter UI components.
- **Mandatory Alternative**: All storage, schema migration, and SQL query execution MUST take place inside `crates/dilang_sqlite` in Rust. Flutter invokes data operations solely via FRB v2 Dart interfaces.

### Rule 2: NO Direct LLM / AI Engine Execution in Flutter / Dart
- **Violations**: Importing HTTP cloud API SDKs (`google_generative_ai`, `openai`), calling external LLM REST endpoints, or bundling C++ inference bindings directly into Dart plugins.
- **Mandatory Alternative**: `crates/dilang_models` handles model lifetime, C++ wrapper FFI (`llama.cpp`, `whisper.cpp`), memory mapping, and token streaming.

### Rule 3: Preserving FSRS v4 Mathematical Integrity
- **Violations**: Modifying FSRS-v4 stability/difficulty calculation formulas, introducing hardcoded interval overrides, or falling back to SuperMemo-2 (SM-2) heuristics.
- **Mandatory Alternative**: Any change to `crates/dilang_fsrs` must pass the benchmark test suite and maintain parity with the official FSRS-4.5 specification.

---

## 3. Code Generation Guardrails

1. **No Swallowed Exceptions or Dummy Fallbacks**: When handling missing files, model loading errors, or audio pipeline failures, code MUST propagate typed errors using `Result<T, E>`. Returning empty dummy strings, catching and ignoring exceptions, or adding silent `try-catch` blocks is strictly forbidden.
2. **No Memory Leaks in C++ / Rust FFI**: Unsafe pointer allocations (`llama_context`, `whisper_context`) must implement Rust's `Drop` trait explicitly to clean up allocated native VRAM/RAM buffers.
3. **No Dynamic Untyped JSON in Dart**: All data passed over FRB v2 must map to concrete Dart classes generated by `flutter_rust_bridge_codegen`.
