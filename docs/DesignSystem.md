# DiLang — Design System Specification

**Version**: 2.0-RESET  
**Status**: Authoritative  

---

## 1. Color Palette Tokens

- **Background**: `#0B1020` (Deep Dark Slate)
- **Surface Container**: `#172033` (Slate)
- **Border / Outline**: `#1E293B` / `#334155` (Dark Muted Slate)
- **Primary Accent**: `#3B82F6` (Bright Azure)
- **Secondary Accent**: `#22D3EE` (Cyan)
- **Accent Highlight**: `#8B5CF6` (Violet)
- **Success**: `#22C55E` (Emerald Green)
- **Warning**: `#F59E0B` (Amber)
- **Error**: `#EF4444` (Coral Red)

---

## 2. Typography & Spacing

- **Font Family**: Primary body font `Inter`, headers `Outfit`.
- **Spacing Grid**: 4dp grid (`4`, `8`, `12`, `16`, `24`, `32`, `48`).

---

## 3. Responsive Breakpoints

- **Desktop (`> 1024px`)**: Fixed left navigation sidebar (240px width) + multi-pane workspace.
- **Tablet (`600px - 1024px`)**: Collapsible navigation drawer + fluid card grid layout.
- **Mobile (`< 600px`)**: Bottom navigation bar + single-column stacked view.
