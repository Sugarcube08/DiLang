# DiLang — Product Roadmap

**Version**: 2.0-RESET  
**Status**: Authoritative  

---

## Milestone 1: Architectural Reset & Core Foundation (Current)
- Unified single Flutter app architecture (`lib/`).
- Authoritative `DiLangRuntime` kernel integration.
- Embedded SQLite engine schema initialization & migrations.
- Clean FSRS-4.5 math engine implementation.

## Milestone 2: Native AI & Hardware Audio Integration
- Native `llama.cpp` C FFI dynamic library bindings for local GGUF execution.
- Whisper local STT audio stream transcription.
- On-device Piper TTS voice synthesis engine.

## Milestone 3: Cross-Platform Release Packaging
- Linux AppImage & Debian package bundle.
- macOS `.dmg` bundle with Metal GPU acceleration.
- Windows `.msi` bundle with DirectML acceleration.
